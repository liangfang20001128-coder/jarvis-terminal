# 贾维斯全息智能终端 · 设计文档

- 日期：2026-08-07
- 状态：方向已确认（原型 v3 交互响应版），待用户审阅本规格
- 项目：本地个人全息智能终端（Web 应用）
- 第一阶段范围：终端 UI 骨架 + 交互系统 + 智能环境调色 + 语音切换框架（演示数据）

## 1. 背景与目标

做一个“钢铁侠贾维斯”式的电脑终端智能体：科技感、可交互、实时感。它不只是静态面板，而是一个**活的系统**——每个模块、每次操作都有光效与运动响应，并随着环境和用户行为不断自适应。

本阶段目标：先把终端本身做出来并能跑起来——全息投影风格、毛玻璃模块、动态光效、交互响应、语音切换模式的框架，全部使用演示数据，为后续接入真实热点、AI 前沿情报、行为习惯算法留好接口。

## 2. 核心设计原则（所有交互必须遵循）

> **没有“定死”的 UI。任何一次交互，都要产生实时的光效、大小、纵深变化。**

1. **响应优先**：光标、悬停、点击、语音、键盘聚焦都必须触发可见的实时反馈（位移、缩放、发光、变色、加速）。
2. **纵深与光**：界面是 3D 空间而非平面。模块悬浮在不同深度，光效（光晕、光束、扫描线、脉冲）是交互的“肌肉”。
3. **聚焦即状态**：任一时刻只有一个模块处于聚焦状态（放大、发光、连线点亮），其余模块退后、变暗、降饱和。
4. **环境自适应**：全息色调跟随系统时间与系统外观自动切换，同时保留手动覆盖。
5. **图层秩序与动态避让**：层级固定（背景 < 光束/连线 < 核心 < 模块 < 顶部/轨道/指令栏 < 覆盖层），前台文字不压模块；模块与顶栏、轨道、指令栏冲突时自动下移调整，禁止出现遮挡排版错误。
6. **克制地炫**：动效围绕交互发生，不为了动而动；尊重系统“减少动态效果”偏好。

## 3. 范围

### 本阶段包含（Phase 1 · 骨架）

- 全屏全息终端 Web 应用（本地运行，浏览器全屏打开）
- 全息视觉系统：毛玻璃模块、全息网格地面、粒子场、光束、扫描线、HUD 角标、竖排标题轨
- 中央实时地球核心：3D 地球（昼夜分界线随真实时间移动）、云层、大气光晕、环绕光环、状态文字
- 立体轨道排版：模块环绕核心、各有倾斜与纵深、脉冲光线连接
- 七个交互模式：
  - 对话（Chat）—— 聚焦时点亮指令栏，模拟语音输入就绪
  - 全球热点（Hot）—— 滚动信息流（演示数据）
  - AI 模型（AI）—— 神经网络架构图 + Token 用量条（演示数据）
  - 行为洞察（Habit）—— 柱状图呼吸动画（演示数据）
  - 影音（Media）—— 视频 / 音乐入口（演示数据）
  - 空间（Space）—— 文档 / 游戏 / 工作空间入口（演示数据）
  - 时运（Fate）—— 实时时间（缩小弱化）+ 农历 + 周易卦象 + 今日运势，“起卦”可重掷（交互模块）
- 交互系统：光标视差、光标光晕、悬停放大发光、其余模块退后变暗、点击/轨道切换聚焦、核心加速响应
- 图层自动避让：模块与顶栏/轨道/指令栏重叠时动态下移，前台文字不遮挡模块
- 模块自由拖动：所有模块可按住拖动到任意位置，位置本地持久化，刷新后保留
- 自动板块排版：顶栏「✦ 自动排版」按钮，按使用优先级习惯（默认优先级 + 使用次数权重）把模块排成整齐三列、互不重叠；再点恢复自由排版，拖过的位置保留
- 三层原位放大（Apple 风格）：每个模块都有三层内容——第一层悬浮概览、第二层从模块自身原位放大为详情视图、第三层继续放大为全屏深潜视图（无侧滑抽屉，缩放动效如 macOS）；放大时实时钳制边界，越界自动收缩/回位
- 智能环境调色：按时段自动匹配 4 套色调（清晨 / 白昼 / 黄昏 / 深夜）+ 手动预览 + 偏好持久化
- 语音框架：语音识别（支持时）+ 语音合成（JARVIS 式回应）+ 键盘输入兜底
- Codex 智能体桥接：本地 `agent-server.mjs` 把终端指令转发给 Codex CLI（读只沙箱、不落盘会话），Codex 以「贾维斯」身份回复，并可通过 `[[module:模式ID]]` 协议真实操控模块；CLI 不可用时自动降级为内置路由
- 模块调用 API：`window.jarvis` 暴露模块打开/聚焦、起卦、报时、状态查询等接口，对话、语音、指令均可调用
- 本地数据层：`localStorage` 保存主题偏好、活跃模式、行为记录（为后期算法留数据）
- 真实数据接入（本阶段已启用）：热点 = 36氪/少数派/澎湃/Hacker News 实时聚合；AI = arXiv 最新论文 + Hugging Face 热门模型榜；洞察 = 真实记录本地使用时长/时段/模块排行；影音 = 可在线播放的公开音视频流；空间 = 桥接服务只读读取真实项目文件；时运 = 完整《周易》64 卦辞原文；对话 = Codex
- 应用启动能力：`agent-server.mjs` 通过 `JARVIS_LAUNCH` 白名单授权 `open -a` 启动本地应用；游戏登录地址通过 `JARVIS_GAME_URL` 配置（默认未启用，防误操作）

### 本阶段不包含（后续阶段）

- 真实全球热点 / 新闻 API 接入
- 真实 AI 前沿情报跟踪与模型数据
- 真实行为习惯迭代算法
- 真实视频 / 音乐 / 文档 / 游戏 / 工作空间打通
- 真实大模型对话
- 壁纸背景感知（需系统级权限，列为研究项）

## 4. 视觉设计

### 4.1 设计方向

已确认原型：**全息终端 v3（交互响应版）**。参考 Apple Liquid Glass 的透明毛玻璃质感，叠加全息投影语言（网格、扫描线、粒子、光束、分光文字），目标是“科幻电影里的终端真的在跑”。

### 4.2 色彩系统（环境色调）

以 CSS 自定义属性驱动，四套时段色调 + 手动覆盖：

| 时段 | 主色 `--acc1` | 次色 `--acc2` | 能量色 `--mag` | 氛围 |
| --- | --- | --- | --- | --- |
| 清晨 dawn | `#ffb199` | `#b58cff` | `#ff8fb0` | 紫粉晨光 |
| 白昼 noon | `#8fd0ff` | `#3f8cff` | `#ff9d5c` | 清亮天蓝 |
| 黄昏 dusk | `#ffb36b` | `#ff6f91` | `#c26bff` | 琥珀晚霞 |
| 深夜 night | `#7ce7ff` | `#4f9dff` | `#ff5fa2` | 经典青蓝 |

底色为深空渐变（`#050a16 → #01030a`），背景氛围光随色调变化（`--bgA / --bgB`）。

### 4.3 字体

- 界面文字：苹方 / PingFang SC（字重 200–600，大字号 + 宽字距营造未来感）
- 数据文字：SF Mono / Menlo / 等宽字体（时钟、Token、状态、编号）
- 标题：细字重大字号 + 分光文字阴影（青蓝主色 + 品红/青色边缘）

### 4.4 签名元素

- **实时地球核心**：3D 地球渲染（Three.js），昼夜分界线按真实 UTC 时间移动，云层缓慢漂移，大气光晕颜色跟随环境色调；外圈环绕光环 + 扩散脉冲
- **立体轨道排版**：模块绕核心悬浮，带 3D 倾斜与纵深，脉冲光线连接
- **扫描线与粒子场**：贯穿全屏的环境动态
- **时运模块**：时间 + 农历 + 周易 + 运势融合的玄学交互模块，起卦翻牌动效

### 4.5 布局

- 顶部：弱化的小时钟（不再大字号突出）+ 语音/状态胶囊
- 中部：实时地球核心（左）+ 环绕模块（热点、AI、洞察、影音、空间、时运）+ 轨道环 + 连接光线
- 底部：模式轨道（对话 / 热点 / AI 模型 / 洞察 / 影音 / 空间 / 时运）+ 指令栏（光标闪烁 + 语音波形）
- 角落：HUD 角标四角固定

## 5. 架构与组件

### 5.1 技术选型

- 纯静态 Web 应用（HTML + CSS + 原生 JS），无构建步骤，本地浏览器直接打开即可运行
- 实时地球使用 Three.js（r128，CDN 加载）；CDN 或 WebGL 不可用时自动降级为 CSS 兜底地球
- 粒子、光束、扫描线用 DOM/CSS 实现；后期如需要可换 Canvas
- 目标浏览器：Chrome / Edge（完整语音识别）、Safari（语音合成 + 键盘兜底）

### 5.2 目录结构

```
贾维斯/
├── index.html              # 终端外壳
├── styles/
│   └── terminal.css         # 全息视觉系统与交互样式
├── js/
│   ├── core.js              # 时钟、状态、启动
│   ├── env-tint.js          # 环境调色（时段 + 系统外观 + 手动覆盖）
│   ├── interactions.js      # 视差、光晕、悬停、聚焦状态机
│   ├── modes.js             # 模式注册表与渲染
│   ├── demo-data.js         # 演示数据（热点、AI、洞察等）
│   ├── speech.js            # 语音识别/合成 + 键盘兜底
│   └── storage.js           # localStorage 偏好与行为记录
├── agent-server.mjs         # 本地桥接服务：Codex 智能体 + 实时数据聚合（/api/hot /api/ai /api/workspace /api/launch /api/chat）
└── docs/superpowers/specs/  # 设计文档
```

### 5.3 模式注册表

每个模式是一个独立单元：`{ id, 名称, 图标, 面板渲染, 聚焦行为, 语音别名 }`。语音别名支持“切换到音乐”“打开视频”“今天运势”等口语化说法。时运模块内部含农历计算（lunar-javascript，CDN 加载，离线时降级提示）、卦象与运势的确定性算法（按日期种子生成，同日结果稳定）。新增模块只需注册一个条目，不侵入其他模块。

### 5.4 数据流

1. 交互事件（光标 / 悬停 / 点击 / 语音 / 键盘）→ `interactions.js` 更新聚焦状态
2. 聚焦状态 → `modes.js` 渲染面板样式 + `core.js` 更新核心/连线/指令栏
3. 环境信号（时间 / 系统外观 / 手动覆盖）→ `env-tint.js` 更新 CSS 变量
4. 用户操作与偏好 → `storage.js` 持久化
5. 对话指令 → `agent-server.mjs`（优先 Codex CLI，读只沙箱）→ 回复文本 + 模块指令 → 终端执行 `window.jarvis`
6. 实时数据 → 桥接服务定时抓取（热点 60s / AI 10min / 空间按需）→ 模块面板渲染；网络失败自动回退演示数据并标注

## 6. 交互规范（所有 UI 遵循）

| 交互 | 反馈 |
| --- | --- |
| 光标移动 | 整个空间 3D 视差倾斜，光标处光晕跟随 |
| 悬停模块 | 模块放大发光飞到最前，内部动效加速，连线点亮，其他模块退后变暗 |
| 点击模块 / 模式轨道 | 切换聚焦：目标模块放大发光，其余退后变暗，核心响应 |
| 对话模式 | 指令栏点亮，模拟语音就绪 |
| 时运 · 起卦 | 卦象翻牌动画 + 发光，运势条流动填充，结果随时间片变化 |
| 拖动模块 | 模块随指针移动，吸附边界内，松手后位置存入本地，刷新保留 |
| 拖动联动 | 拖动模块时，核心到模块的虚线连线实时跟随模块新位置；缩放窗口与加载保存位置时同步重算 |
| 自动排版 | 按优先级习惯重排全部模块为三列网格，避免重叠；使用次数写入本地，影响后续优先级 |
| 点击模块 | 从模块自身原位放大展开第二层详情；再点“深入”继续放大到第三层；Esc / ✕ 反向缩小还原 |
| 点击空白处 | 任意第二/三层展开时，点击面板以外的空白区域（背景、网格、顶栏）即收拢回归首页 |
| 模块放大 | 实时测量边界，若放大后超出终端边缘，自动降低放大倍率，保证不越界 |
| 语音指令 | 模式切换动画同点击；合成语音回应“已切换到 XX 模式” |
| 键盘 | 指令栏可输入命令；`Tab` 可见焦点环 |
| 对话输入 | 回车发送到智能体桥接；回复打字机显示于对话深潜面板；回复携带的模块指令自动执行 |
| 减少动态效果偏好 | 关闭视差/粒子/扫描等非必要动画 |

所有模块均参与图层自动避让：与顶栏、轨道、指令栏或其他前台元素冲突时，由排版引擎自动下移，避免遮挡。

## 7. 智能环境调色

- **时段自动匹配**：按系统时间映射 4 套色调（5–8 清晨 / 8–17 白昼 / 17–20 黄昏 / 其余深夜）
- **系统外观**：读取 `prefers-color-scheme`，深色模式用深空底；浅色模式调亮背景氛围并提高玻璃面板透明度（本阶段实现基础版）
- **手动覆盖**：用户可锁定任意色调，偏好存入 `localStorage`
- **后续研究**：壁纸 / 环境光感知需要系统权限，列为独立研究项，不在本阶段承诺

## 8. 语音交互

- 识别：`webkitSpeechRecognition` / `SpeechRecognition`（Chrome/Edge）；Safari 不支持时自动降级为键盘输入，并在 UI 上标注“语音仅限 Chrome”
- 合成：`speechSynthesis` 中文语音（Safari 可用），配合打字机式文字回显
- 命令集：切换模式、报时、状态查询、开启/关闭环境自动调色

## 9. 数据处理与错误处理

- 演示数据全部标注“演示”，与真实数据源解耦
- 后期接入真实 API 时：加载中、失败、空数据三种状态都有明确 UI（不静默失败）
- `localStorage` 读写失败时降级为内存态，不影响运行

## 10. 无障碍与性能

- 键盘可操作（焦点可见、回车触发）
- `prefers-reduced-motion` 时关闭非必要动画
- 粒子数量与动画帧率在低性能设备上自动降级（按帧率检测）
- 目标：1080p 全屏流畅（≥45fps）

## 11. 测试与验收

### 手动验证清单（本阶段验收标准）

1. 浏览器打开即运行，无控制台报错
2. 时钟 / 日期实时更新
3. 环境调色按真实系统时间自动匹配；手动预览与“智能跟随”切换正常；刷新后偏好保留
4. 光标视差、光晕、悬停放大、其余退后变暗、点击切换聚焦全部生效
5. 六个模式均可切换，演示数据正常渲染
6. 语音：Chrome 下“切换到音乐”等命令生效；Safari 下键盘输入兜底可用
7. Safari 与 Chrome 各验证一轮；窗口缩放（≥1280×720）不破版
8. 实时地球：3D 地球渲染正常，昼夜分界线随时间变化，云层/大气光晕正常，色调切换后光晕联动变色；断网或 CDN 失败时 CSS 兜底地球可用
9. 时运模块：农历与真实农历一致（抽查已知日期）、卦象同日稳定、起卦动画与结果刷新正常、运势条动画正常
10. 图层避让：各窗口宽度下，模块与顶栏/轨道/指令栏无重叠；时钟不再大字号突出
11. 三层原位放大：七个模块均可原位放大第二层与第三层，内容完整无空白，Esc/✕ 反向缩小还原正常，无侧滑抽屉残留
12. 放大边界：悬停/聚焦/放大所有边缘模块（含空间模块），均不超出终端边界
13. 自由拖动：模块可拖动至任意位置且不出界；刷新后位置保留；拖动的模块不再被自动避让覆盖
14. 智能体桥接：`GET /api/status` 返回 Codex 可用状态；`POST /api/chat` 返回回复与模块指令；CLI 不可用时降级路由正常
15. 模块可调用：输入“打开音乐 / 今日运势 / 报时”等，模块系统被真实触发（切换聚焦 + 原位放大 + 起卦），对话面板显示回复
16. 点击空白回归：第二层与第三层展开时，点击面板外任意空白区域均能收拢回首页；面板内部点击不受影响
17. 拖动联动：拖动任意模块，虚线连线实时跟随；刷新加载保存位置后连线位置正确；窗口缩放后连线不漂移
18. 排版细节：拖动提示与模块标题无重叠（提示为底部胶囊）；指令栏宽度适中（不超过屏宽 56%）
19. 自动排版：点按钮后模块成三列网格、互不重叠；高优先级（热点/AI 默认优先，使用次数加权）排在靠前位置；再点恢复自由排版且拖动位置不丢失
20. 使用习惯：模块激活（点击/轨道/语音/对话指令）次数写入 localStorage，刷新后优先级排序随之变化

## 13. 风险

- 语音识别跨浏览器不一致 → 键盘兜底 + 明确标注
- `color-mix` / `backdrop-filter` 老旧浏览器兼容 → 提供降级样式（纯色半透明底）
- WebGL / CDN 不可用 → CSS 兜底地球 + 网络提示
- 农历库 CDN 不可用 → 显示“离线库未加载”，卦象/运势仍可用（纯本地确定性算法）
- 壁纸感知权限不可用 → 保持时段 + 系统外观方案，不做承诺

## 14. 部署与永久运行

- 可部署版本位于 `web/index.html`（独立网页），GitHub Actions（`.github/workflows/pages.yml`）在推送 `main` 后自动发布到 GitHub Pages，终端永久可访问
- 本地永久运行：`deploy/install-agent-service.sh` 将智能体服务安装为 macOS 登录自启（launchd），日志在 `~/.jarvis/`
- 桥接服务地址由 `web/config.js` 控制（默认 `http://127.0.0.1:8787`）；云端部署时改为线上 API 地址，未配置时页面以演示数据运行不白屏
